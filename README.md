## Hi, I'm Zach 👋

Network admin in Buffalo, NY, currently working toward a B.S. in Cybersecurity. By day I'm knee-deep in Microsoft 365 tenants, Entra ID, and Conditional Access policies for MSP clients. By night (and most weekends, if I'm honest) I'm building small tools that make the tools I use every day less annoying.

---

### Things I've built

| Project | What it does |
|---|---|
| [`Connectwise-MCP-Server`](https://github.com/taddiemason/Connectwise-MCP-Server) | A Docker-packaged bridge exposing 18 read-only ConnectWise tools (tickets, assets, contacts, agreements, financials) so AI assistants can actually query PSA data instead of me tabbing over to check it manually |
| `m365-entra-audit-suite` | PowerShell + Graph API suite that audits Global Admin roles, Conditional Access/MFA policies, Named Locations, and licensing waste across every tenant I manage — flags anything that looks like PASS / REVIEW / AT RISK |
| [`Gmail-MCP-Server`](https://github.com/taddiemason/Gmail-MCP-Server) | Middleware that turns plain language into Gmail API calls — OAuth 2.0 with auto-refreshing tokens, attachment parsing, label management |
| `sms-ai-chatbot` | Routes SMS through a Groq-powered natural-language layer via the Vonage API — mostly built to see if I could |
